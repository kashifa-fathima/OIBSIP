# Customer Segmentation Analysis

This project performs customer segmentation using machine learning techniques to identify groups of customers with similar characteristics and purchasing behaviour.

## Objective

The objective of this project is to analyse customer data and group customers into meaningful segments using the K-Means clustering algorithm.

## Tools and Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Project Workflow

- Load and inspect the customer dataset
- Perform data cleaning and preprocessing
- Select relevant features for customer segmentation
- Determine the optimal number of clusters
- Apply the K-Means clustering algorithm
- Analyse the characteristics of each customer segment
- Visualise the customer clusters

## Machine Learning Model

This project uses the **K-Means Clustering** algorithm, an unsupervised machine learning technique used to group similar customers into clusters.

## Dataset

The dataset contains customer information and relevant features used to identify different customer groups based on their characteristics and behaviour.

## Results

The K-Means clustering model successfully grouped customers into different segments. These segments can help businesses better understand customer behaviour and support targeted marketing and business strategies.
