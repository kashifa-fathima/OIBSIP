# Exploratory Data Analysis on Retail Sales

This project performs Exploratory Data Analysis (EDA) on a retail sales dataset using Python.

## Objective
To explore the retail sales dataset, identify patterns and trends, and generate meaningful insights through data analysis and visualisation.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Tasks
- Data loading and inspection
- Data cleaning
- Exploratory Data Analysis
- Sales trend analysis
- Product analysis
- Data visualisation

## Dataset
The dataset contains retail transaction information used to analyse sales patterns and customer purchasing behaviour.
